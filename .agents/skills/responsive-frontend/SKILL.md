# responsive-frontend

Usa los recorridos de [diseño de interfaz](../../../docs/requirements/interface_design.md) §§4–7. Para una cita incorrecta compara el par documento/página de la respuesta, el enlace generado, la petición de imagen y la página mostrada. Si el error ya está en la respuesta, sigue la recuperación con el skill de corpus.

Ejercita por teclado la apertura y cierre del visor y el retorno del foco. Verifica carga, ausencia de evidencia, error recuperable y nombres largos. Comprueba 320, 375, 768, 1024 y 1440 px, legibilidad de tablas, ausencia de desbordamiento global y anuncios de progreso sin razonamiento privado. Conserva evidencia de T-09/T-12 con el viewport, el resultado y las limitaciones observadas. Si corresponde usar Impeccable, verifica antes [su admisión](../../../docs/execution/TOOLCHAIN.md).
