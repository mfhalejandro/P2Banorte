# Herramientas del arnés

Python 3.11+ y Git local ejecutan los dos verificadores. El formato Markdown y el frontmatter YAML permiten descubrir los skills en Codex o abrirlos desde AGENTS en otro agente.

| Integración | Fuente designada por el estándar | Estado en el proyecto |
|---|---|---|
| Superpowers | obra/superpowers | Adaptador local de desarrollo disponible. Versión externa pendiente de admisión. |
| Impeccable | pbakaus/impeccable | Integración descrita en responsive-frontend. Versión externa pendiente de admisión. |

Antes de importar una versión, aplica el [gate de admisión](../quality/SKILL_ADMISSION_GATE.md) y registra aquí procedencia, versión o commit, hash, licencia, compatibilidad, fecha, responsable y desactivación.
