# P2Banorte · fuentes del proyecto

El producto es un chat financiero que fundamenta respuestas con páginas de PDF locales. El [PRD](requirements/PRD.md) identifica objetivos y criterios AC-01 a AC-27. El [estándar](requirements/estandar_arnes_nativo_ingenieria.md) gobierna el desarrollo. La [tarea profesional](requirements/professionals_task.md) fija las fases y los casos T-01 a T-16.

El [estado de ejecución](execution/PROGRESS.md) identifica la etapa activa y sus decisiones pendientes. El [protocolo](execution/PROTOCOL.md) gobierna arranque y continuidad. Consulta la [matriz de trazabilidad](quality/TRACEABILITY_MATRIX.md) para encontrar evidencia de un criterio.
