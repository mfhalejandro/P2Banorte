# Diseños detallados

SDD significa *Software Design Document*. Si una solución aprobada requiere explicar interacciones, contratos, datos, fallos, despliegue o reversión, asigna el siguiente identificador permanente en el [registro](SDD_REGISTRY.md) y usa la [plantilla](SDD_TEMPLATE.md). Enlaza la spec y los ADR que condicionan el diseño. El plan se deriva de las versiones aprobadas aplicables según las secciones 7.9 y 13.10 del [estándar](../../requirements/estandar_arnes_nativo_ingenieria.md).
